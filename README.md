## Описание

Программа автоматически парсит прогноз погоды на 7 дней для указанного города с сайта Яндекс.Погоды, обрабатывает данные и сохраняет результаты в удобном формате. Проект реализует полный цикл работы: от получения данных до их сохранения в структурированном виде.

## Возможности

- ✅ **Парсинг прогноза на 7 дней** - автоматическое извлечение данных о погоде
- ✅ **Детальный прогноз по времени суток** - утром, днем, вечером, ночью
- ✅ **Магнитное поле** - информация о геомагнитной активности
- ✅ **Метеорологические данные**:
  - Температура воздуха и ощущаемая температура
  - Атмосферное давление
  - Влажность воздуха
  - Погодные явления (дождь, снег, пасмурно и т.д.)
  - Скорость ветра
- ✅ **Автоматические расчеты**:
  - Средняя дневная температура (утром, днем, вечером)
  - Обнаружение резких изменений давления (≥ 5 мм рт.ст.)
- ✅ **Экспорт в Excel** - структурированные данные с форматированием
- ✅ **SQLite база данных** - история всех запросов
- ✅ **HTTP API** - RESTful веб-сервис для интеграции

## База данных

### Структура

Программа использует SQLite базу данных `weather_data.db` для хранения истории запросов.

### Таблица `weather_requests`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Уникальный идентификатор запроса (PRIMARY KEY, AUTOINCREMENT) |
| `city` | TEXT | Название города (входной параметр) |
| `request_date` | DATETIME | Дата и время выполнения запроса |
| `status` | TEXT | Результат работы: `'success'` или `'error'` |
| `error_message` | TEXT | Сообщение об ошибке (NULL, если успешно) |

### Примеры запросов

#### Просмотр всех запросов

```sql
SELECT * FROM weather_requests ORDER BY request_date DESC;
```

#### Статистика по городам

```sql
SELECT city, COUNT(*) as requests_count, 
       SUM(CASE WHEN status = 'success' THEN 1 ELSE 0 END) as success_count
FROM weather_requests
GROUP BY city;
```

#### Ошибки за последний день

```sql
SELECT * FROM weather_requests 
WHERE status = 'error' 
  AND request_date >= datetime('now', '-1 day')
ORDER BY request_date DESC;
```

## Формат Excel файла

### Структура файла

Excel файл содержит следующую структуру:

1. **Заголовок** (строка 1):
   - Объединенные ячейки A1:G1
   - Текст: "Прогноз погоды на 7 дней для города: {название_города}"
   - Синий фон, белый текст

2. **Дата запроса** (строка 2):
   - Текст: "Дата запроса: {дата и время}"
   - Курсив

3. **Данные по дням** (начиная со строки 3):
   - Для каждого из 7 дней:
     - **Заголовок дня**: Дата и информация о магнитном поле
     - **Таблица данных**:
       | Время суток | Температура, °C | Ощущаемая, °C | Давление, мм рт.ст. | Влажность, % | Явление | Скорость ветра |
       |-------------|-----------------|---------------|---------------------|--------------|---------|----------------|
       | утром       | +18             | +18           | 748                 | 80           | облачно | 3 м/с          |
       | днем        | +22             | +22           | 748                 | 63           | ясно    | 3 м/с          |
       | вечером     | +20             | +19           | 749                 | 72           | облачно | 3 м/с          |
       | ночью       | +16             | +15           | 749                 | 85           | ясно    | 3 м/с          |
     - **Средняя дневная температура** (если вычислена)
     - **Предупреждение о давлении** (если обнаружено резкое изменение)

### Форматирование

- **Заголовки таблиц**: серый фон, жирный шрифт
- **Границы**: все ячейки с данными имеют границы
- **Выравнивание**: данные выровнены по центру
- **Предупреждения**: желтый фон, красный текст

### Имя файла

Формат: `weather_forecast_{город}_{дата}_{время}.xlsx`

Пример: `weather_forecast_moscow_20251121_190611.xlsx`

## Обработка данных

### Средняя дневная температура

**Формула**: Среднее арифметическое температуры утром, днем и вечером

```
Средняя дневная температура = (Т_утром + Т_днем + Т_вечером) / 3
```

**Пример:**
- Утром: +18°C
- Днем: +22°C
- Вечером: +20°C
- **Средняя**: (18 + 22 + 20) / 3 = 20.0°C

**Примечание**: Температура ночью не учитывается в расчете.

### Обнаружение изменения давления

Программа анализирует изменения атмосферного давления в течение дня.

**Алгоритм:**

1. Находит минимальное и максимальное значение давления за день
2. Вычисляет разницу: `разница = максимум - минимум`
3. Если разница ≥ 5 мм рт.ст.:
   - Сравнивает первое (утром) и последнее (ночью) давление
   - Если последнее > первого → **"ожидается резкое увеличение атмосферного давления"**
   - Если последнее < первого → **"ожидается резкое падение атмосферного давления"**
   - Если равны, определяет по позициям минимума и максимума
4. Если разница < 5 мм рт.ст. → предупреждение не добавляется

**Примеры:**

- Давление: 748 → 751 → 752 → 750 (разница 4 мм) → предупреждения нет
- Давление: 748 → 755 → 752 → 750 (разница 7 мм, последнее > первого) → "ожидается резкое увеличение"
- Давление: 755 → 752 → 748 → 746 (разница 9 мм, последнее < первого) → "ожидается резкое падение"

## API документация

### Базовый URL

```
http://localhost:5000
```

### Эндпоинты

#### GET /weather

Получить прогноз погоды в формате Excel.

**Параметры запроса:**

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `city` | string | Да | Название города |

**Пример запроса:**

```bash
curl "http://localhost:5000/weather?city=Moscow" --output forecast.xlsx
```

**Ответ:**

- **Content-Type**: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- **Content-Disposition**: `attachment; filename="weather_forecast_{city}_{timestamp}.xlsx"`
- **Тело**: Excel файл (бинарные данные)

**Коды ответа:**

- `200 OK` - успешный запрос, файл возвращен
- `500 Internal Server Error` - ошибка при обработке запроса

#### POST /weather

Получить прогноз погоды в формате Excel (POST запрос).

**Тело запроса (JSON):**

```json
{
  "city": "Moscow"
}
```

**Пример запроса:**

```bash
curl -X POST "http://localhost:5000/weather" \
  -H "Content-Type: application/json" \
  -d '{"city": "Moscow"}' \
  --output forecast.xlsx
```

**Ответ:** Аналогичен GET /weather

### Обработка ошибок API

При возникновении ошибки API возвращает:

**HTTP 500 Internal Server Error**

```json
{
  "detail": "Ошибка при получении прогноза погоды: {описание ошибки}"
}
```

Ошибка также сохраняется в базу данных с `status='error'`.

## Обработка ошибок

### Типы ошибок

1. **Сетевые ошибки**:
   - Таймаут запроса
   - Отсутствие интернет-соединения
   - Недоступность сайта Яндекс.Погоды

2. **Ошибки парсинга**:
   - Изменение структуры HTML на сайте
   - Отсутствие данных для города

3. **Ошибки записи**:
   - Проблемы с доступом к файловой системе
   - Ошибки базы данных

### Поведение при ошибках

- **CLI режим**:
  - Ошибка логируется в файл и консоль
  - Информация сохраняется в БД с `status='error'`
  - Программа завершается с кодом 1

- **API режим**:
  - Возвращается HTTP 500
  - Ошибка логируется
  - Информация сохраняется в БД

Проект использует следующие библиотеки:

- **requests** (≥2.31.0) - HTTP клиент для запросов
- **beautifulsoup4** (≥4.12.0) - парсинг HTML
- **lxml** (≥4.9.0) - быстрый XML/HTML парсер
- **openpyxl** (≥3.1.0) - работа с Excel файлами
- **python-dateutil** (≥2.8.0) - работа с датами
- **fastapi** (≥0.104.0) - современный веб-фреймворк
- **uvicorn[standard]** (≥0.24.0) - ASGI сервер
- **pydantic** (≥2.5.0) - валидация данных
- **sqlalchemy** (≥2.0.0) - ORM для работы с БД

### Архитектура

Проект следует принципам разделения ответственности:

- **Парсинг** (`parsers/`) - извлечение данных из HTML
- **Обработка** (`parsers/processors.py`) - бизнес-логика
- **Хранение** (`database/`) - работа с БД
- **Экспорт** (`parsers/excel_generator.py`) - генерация файлов
- **API** (`api/`) - веб-интерфейс

### Расширение функциональности

Для добавления новых функций:

1. **Новые данные**: расширьте модели в `parsers/models.py`
2. **Новая обработка**: добавьте функции в `parsers/processors.py`
3. **Новые форматы экспорта**: создайте новый генератор по аналогии с `excel_generator.py`
4. **Новые эндпоинты**: добавьте роуты в `api/routes.py`

## Лицензия

Проект создан в учебных целях.

## Поддержка

При возникновении проблем:

1. Проверьте логи в файле `weather_parser.log`
2. Убедитесь, что все зависимости установлены
3. Проверьте доступность сайта Яндекс.Погоды
4. Убедитесь, что указан корректный город
